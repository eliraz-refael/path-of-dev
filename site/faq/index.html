The basics

What is Path of Dev?

An RPG you play while you work in Claude Code. A plugin (the mod) grades each prompt you write and reports what you get done: tests going green, commits, merged pull requests. The game server turns that into XP, levels, loot, missions and a pixel pet, drawn in a band above your prompt. It's meant to make good habits a little more fun, not to get in your way.

Is it free?

Yes. It's open source under the MIT license, and the online server costs nothing to play on. Grading uses your own Claude account: see does it cost tokens.

What do I need?

Claude Code on macOS or Linux, and a GitHub account to play online. Get started has the details.

Does it work on Windows?

Untested. Nobody has played it on Windows yet: the mod may work there, the local server needs Unix sockets, and the history import reads big transcripts through cat. If you try it, tell us how it went.

Your code and data

Is my code sent anywhere?

Not to the game. Your code, your prompts and Claude's answers never reach the game server. Grading is one call to Haiku made by your own Claude Code, so a prompt goes to Anthropic just as every prompt you send Claude does, and only the scores go on to the game server. Repo names don't go either: online, the mod sends opaque keys in their place. Profile & privacy lists exactly what is sent.

Who can see my progress?

Nobody, until you run /pathofdev profile public. Then your page at pathof.dev/u/<your-github-login> shows your level and the sections you choose. /pathofdev profile private takes it down again at once.

What can it do with my GitHub account?

Nothing. Signing in asks GitHub for no permissions at all: GitHub only tells the server who you are. Merges are checked by the GitHub CLI on your own machine, if you have it, and only their size and whether the repo is yours are sent.

How do I take my data out, or delete it?

/pathofdev account export writes everything the online server keeps of you to files; /pathofdev account delete <your-github-login> deletes it. See export and delete.

Speed and cost

Does it slow Claude Code down?

No. Your prompt goes to Claude first and untouched; grading runs after, in the background, and never holds a prompt back. What the mod sends goes out in batches in the background too. The one thing it does in line is quick: before a shell command that commits, it reads where the repo's HEAD is, so a commit can be told from an amend.

Does it cost tokens?

A little. Each graded prompt is one short call to Haiku, Claude's smallest model, on your own Claude account, so it counts toward your usage like anything else Claude Code does. The grading instructions are cached and the reply is short. Prompts under 6 words aren't graded at all; to grade fewer, raise Words to grade a prompt in the settings.

Can I play offline, or only on my own machine?

Yes. Without a network the mod keeps what you do in a queue and sends it when the server answers again. To keep everything on your own disk, play on a local save: run the game server from a clone of the repo and point the mod at it with /pathofdev server play. See playing locally.

Playing

I've used Claude Code for months. Does that count?

It can show, but it doesn't pay. /pathofdev import history counts your work from before Path of Dev from Claude Code's own transcripts on your machine (prompts, sessions, projects, days, your longest streak, test runs and commits) and sends only the counts. It gives no XP or badges, so a long history doesn't put you ahead, and it shows on your profile only if you choose. See the history import.

Can I cheat, or farm XP?

Not for long. Every kind of XP has a daily limit, the prompt rate drops after the 20th prompt of the day, the same commit or test fix counts once, an opened pull request pays nothing, tiny merges and merges on your own repos pay less, and gold can't buy XP. Fair play has the full list. It's still a game run on trust; if you find a hole, report it.

Why wasn't my prompt graded?

Prompts under 6 words, slash commands and prompts you didn't type yourself aren't graded. If Haiku doesn't answer in time, that prompt goes ungraded too. /pathofdev last shows the last one that was.

Why didn't my merge pay?

A merge pays when you run gh pr merge in a Claude Code session, or when a pull request the mod saw you open in a session is merged anywhere within 30 days. For the second, the GitHub CLI must be installed and signed in to the account that wrote it. Merges from before you installed the mod don't count.

Why do some rows say “coming”?

A first contribution, a bug fixed, review feedback acted on and an issue closed will pay once the server can confirm them with GitHub. That check is still being built, so today they earn nothing.

Is there a leaderboard?

Not yet. For now, your public profile is the place to show your progress.

Can I play on more than one machine?

Yes, online: install the mod and run /pathofdev login on each, with the same GitHub account, and they share one save. A local save lives on the machine it's on.

The band is distracting. Can I turn it down?

Yes. Set Band to line to keep only a status line under the prompt, Celebrations to reduced or off, and Reward toasts off. /pathofdev pet hide takes the pet off the band. See the settings.

Updating and removing

How do I update?

Run claude plugin update pathofdev@path-of-dev in your shell and restart Claude Code, or use Update now in /plugin. Playing online, the band tells you when a new version is out. Updating also shows how to turn on auto-update.

How do I uninstall it?

Run claude plugin uninstall pathofdev@path-of-dev, or remove it in /plugin. Your online account stays until you delete it with /pathofdev account delete <your-github-login>; a local save stays in ~/.pathofdev until you remove the folder.

The project

What's the companion?

A terminal app, pathofdev watch, that you'll run beside Claude Code to see your pet, your level and your missions at a glance, without opening the pane. It's being built in the open: an early version plays against a local save, and it isn't released yet. There's no date for it.

Coming soon: the companion app, and work GitHub confirms paying XP.

Where do I report a bug, or ask for something?

On GitHub: open an issue. Say what you ran, what you expected, and what the band or /pathofdev server said.

Is it made by Anthropic?

No. Path of Dev is an independent open-source project and isn't affiliated with Anthropic. Claude Code is a product of Anthropic.
