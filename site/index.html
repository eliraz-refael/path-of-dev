An RPG for your Claude Code sessions

Every prompt you write gets graded. Good ones level you up.

Path of Dev grades each prompt you send against what it needs: a clear ask, the right pointers, a picture of done. The grade turns into XP, loot and a pixel pet that grows with you, and merged pull requests pay the big bonuses.

How a prompt is graded.

A small model grades every prompt of six words or more against what that prompt actually needs: six measures of what it says, each from 0 to 10, and a little more for clear writing and a kind tone. A quick follow-up question isn't marked down for skipping a why it doesn't need.

Up to 15 XP a prompt

Your XP is your grade times one and a half, so a perfect 10 earns 15. Prompts are where the daily XP comes from.

Quality over volume

Spamming prompts doesn't pay. The rate drops as the day goes on.

The game never sees your prompts

Grading runs inside your own Claude Code. The game server receives only the scores, and whether the prompt was spelled clean. Your prompt text, the grader's note and any word it flagged never reach it.

Start playing in a minute.

Path of Dev is a Claude Code plugin. It grades in the background and never holds a prompt back, so you keep working exactly as you do.

  1. Install the mod

    /plugin install pathofdev --marketplace eliraz-refael/path-of-dev

    In Claude Code, then restart it.

  2. Sign in

    /pathofdev server online
/pathofdev login

    Enter the code on github.com. GitHub tells the server only who you are.

  3. Write a prompt

    Ask Claude for something real, in six words or more. A moment later the band above the prompt shows the grade and the XP it earned.
